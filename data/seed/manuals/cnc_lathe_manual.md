# HK-200 CNC 선반 작업 매뉴얼

> 본 매뉴얼은 교육·시연용으로 작성된 가상 장비 문서입니다. 실제 장비의 사양서·취급설명서를 대체하지 않습니다.

---

## 1. 장비 개요

`category: equipment`

HK-200은 봉재(丸棒) 및 단조 소재를 회전시켜 절삭공구로 외경·내경·단면을 가공하는 수치제어 선반입니다. 본 사업장에서는 축류 부품의 황삭·정삭 공정에 사용합니다.

### 1.1 주요 제원

| 항목 | 값 |
|---|---|
| 최대 가공 지름 | 200 mm |
| 최대 가공 길이 | 500 mm |
| 주축 최고 회전수 | 3,500 rpm |
| 척 규격 | 8인치 3조 유압 척 |
| 공구대 | 8각 터릿, 공구 8본 장착 |
| 주축 모터 정격 | 11 kW |
| 절삭유 탱크 용량 | 120 L |
| 기계 총중량 | 2,800 kg |

### 1.2 주요 구성부

- **주축대**: 주축과 척이 장착되는 부분으로, 공작물을 회전시키는 동력을 전달합니다.
- **척**: 공작물을 물어 고정하는 장치입니다. HK-200은 유압으로 척 조를 조입니다. 척 조는 3개이며 마모 시 3개를 한 조로 교체합니다.
- **공구대(터릿)**: 절삭공구를 8본까지 장착하고, 프로그램 지령에 따라 회전하여 사용할 공구를 절삭 위치로 보냅니다.
- **심압대**: 공작물이 길 때 반대쪽 끝을 센터로 받쳐 휨과 진동을 막습니다. 길이가 지름의 3배를 넘는 공작물은 반드시 심압대로 지지합니다.
- **이송축**: 공구대를 좌우로 움직이는 Z축과 앞뒤로 움직이는 X축으로 구성됩니다.
- **절삭유 장치**: 절삭유를 가공점에 분사하여 열을 식히고 칩을 씻어냅니다.
- **방호덮개**: 가공 중 칩과 절삭유가 튀는 것을 막는 문입니다. 도어 인터록이 걸려 있어 문이 열리면 주축이 회전하지 않습니다.
- **조작반**: 전원, 운전 모드, 이송 속도 오버라이드, 비상정지 버튼이 배치되어 있습니다.

### 1.3 작업 구역 표시

기계 정면 1 m 이내는 황색 실선으로 작업자 구역을 표시합니다. 칩 배출구 쪽은 적색 사선으로 표시하며, 운전 중 출입을 금지합니다.

## 2. 작동 원리

`category: process`

### 2.1 절삭의 원리

선반 가공은 **공작물이 회전하고 공구가 직선으로 움직이는** 방식입니다. 회전하는 공작물 표면에 절삭공구의 날 끝을 밀어 넣으면, 재료가 얇게 벗겨지면서 칩이 되어 떨어집니다. 남은 표면이 가공면이 됩니다.

절삭 결과를 결정하는 값은 세 가지입니다.

1. **주축 회전수(rpm)**: 공작물이 1분에 도는 횟수입니다. 지름이 클수록 회전수를 낮춥니다.
2. **이송(mm/rev)**: 공작물이 한 바퀴 돌 때 공구가 움직이는 거리입니다. 이송이 크면 빨리 깎이지만 표면이 거칠어집니다.
3. **절삭 깊이(mm)**: 한 번에 파고드는 깊이입니다. 황삭은 2~3 mm, 정삭은 0.2~0.5 mm를 기준으로 합니다.

### 2.2 절삭유의 역할

절삭점의 온도는 순간적으로 600 ℃를 넘습니다. 절삭유는 세 가지 일을 합니다.

- **냉각**: 공구 날 끝과 공작물의 열을 빼앗아 공구 수명을 늘리고 열변형을 막습니다.
- **윤활**: 공구와 재료 사이 마찰을 줄여 표면을 매끄럽게 합니다.
- **칩 배출**: 가공점에 쌓인 칩을 씻어 내려 칩이 가공면을 긁는 것을 막습니다.

절삭유 농도는 5~8 %를 유지합니다. 농도가 낮으면 녹이 슬고, 높으면 피부염을 일으킵니다.

### 2.3 좌표계와 원점

HK-200은 기계 원점을 기준으로 공구 위치를 계산합니다. 전원 투입 후 원점복귀를 하지 않으면 좌표가 어긋나 공구가 척에 충돌할 수 있습니다. 그래서 전원을 켠 다음 가장 먼저 하는 동작이 원점복귀입니다.

### 2.4 척의 물림 원리

유압 척은 실린더 압력으로 척 조 3개를 동시에 중심 쪽으로 밀어 공작물을 잡습니다. 물림 압력이 낮으면 가공 중 공작물이 빠져나가고, 너무 높으면 얇은 공작물이 찌그러집니다. 표준 물림 압력은 2.5 MPa입니다.

## 3. 표준 작업 절차

`category: instruction`

### 3.1 작업 전 점검 (10분)

1. 보호구를 착용합니다. 안전모, 보안경, 안전화를 착용합니다. **회전체 작업이므로 장갑은 착용하지 않습니다.**
2. 기계 주변 바닥에 절삭유나 기름이 흘렀는지 확인하고, 있으면 닦아냅니다.
3. 절삭유 탱크 잔량이 눈금의 1/3 이상인지 확인합니다.
4. 척 조 3개의 물림면이 칩으로 막혀 있지 않은지 확인합니다.
5. 방호덮개를 여닫아 도어 인터록이 정상 작동하는지 확인합니다. 문을 연 상태에서 주축이 돌면 즉시 작업을 중지하고 관리자에게 보고합니다.
6. 비상정지 버튼을 눌러 보고 복귀시킵니다.
7. 조작반 옆 점검표에 서명합니다.

### 3.2 운전 준비

1. 주전원을 올리고 조작반 전원을 켭니다.
2. 원점복귀 버튼을 눌러 X축과 Z축을 원점으로 보냅니다.
3. 오늘 작업할 프로그램 번호를 확인하고 불러옵니다.
4. 공구대에 지정된 절삭공구가 지정된 번호에 꽂혀 있는지 확인합니다.
5. 공구 보정값(공구 길이·날 끝 반지름)을 확인합니다.

### 3.3 공작물 고정

1. 주축이 완전히 정지한 것을 눈으로 확인합니다.
2. 공작물을 척에 넣고 물림 길이를 확보합니다. 물림 길이는 공작물 지름의 1.5배 이상으로 합니다.
3. 유압 척 페달을 밟아 척을 조입니다.
4. 공작물을 손으로 흔들어 흔들림이 없는지 확인합니다.
5. **척 렌치를 사용했다면 반드시 뽑아서 지정 위치에 걸어 둡니다.** 척 렌치를 꽂아 둔 채 기동하면 렌치가 튀어나가 중대재해로 이어집니다.
6. 길이가 긴 공작물은 심압대 센터로 반대쪽 끝을 지지합니다.

### 3.4 시운전

1. 방호덮개를 닫습니다.
2. 이송 속도 오버라이드를 25 %로 낮춥니다.
3. 단일블록 모드로 프로그램을 한 줄씩 실행하며 공구 경로를 확인합니다.
4. 첫 번째 공작물을 가공한 뒤 치수를 측정합니다. 외경 공차는 ±0.05 mm입니다.
5. 치수가 맞으면 오버라이드를 100 %로 올리고 연속 운전으로 전환합니다.

### 3.5 연속 운전 중 관리

- 가공 중에는 방호덮개를 열지 않습니다.
- 20개마다 1개를 뽑아 치수를 측정합니다.
- 칩이 공구에 감기면 즉시 이송을 정지하고, 주축이 멈춘 뒤 칩 갈고리로 제거합니다. **맨손으로 칩을 만지지 않습니다.**
- 이상 소음, 진동, 타는 냄새가 나면 즉시 운전을 중지합니다.

### 3.6 작업 종료

1. 프로그램을 정지하고 공구대를 원점으로 보냅니다.
2. 주축 정지를 확인한 뒤 공작물을 꺼냅니다.
3. 칩받이의 칩을 지정 용기에 비웁니다.
4. 기계 표면과 척 조의 칩을 청소합니다.
5. 조작반 전원과 주전원을 차단합니다.
6. 작업일지에 생산 수량과 특이사항을 기록합니다.

## 4. 안전 수칙

`category: safety`

### 4.1 반드시 지켜야 할 사항

- **회전 중인 척, 공작물, 공구에 절대 손을 대지 마십시오.**
- **선반 작업 중에는 장갑을 착용하지 마십시오.** 장갑이 회전체에 감기면 손이 함께 말려 들어갑니다.
- 긴 소매는 걷어 올리고 단추를 채웁니다. 넥타이, 목걸이, 반지는 착용하지 않습니다.
- 머리카락이 어깨보다 길면 묶고 안전모 안에 넣습니다.
- 방호덮개를 임의로 열거나 도어 인터록을 무효화하지 마십시오. 인터록 무효화는 징계 대상입니다.
- 척 렌치를 꽂아 둔 채로 주축을 기동하지 마십시오.
- 기계가 도는 동안 자리를 비우지 마십시오.
- 2인 이상이 함께 작업할 때는 기동 전 **"기동합니다"**라고 큰 소리로 알리고 상대의 응답을 확인합니다.

### 4.2 주요 위험 요인

| 위험 | 발생 상황 | 예방 조치 |
|---|---|---|
| 감김·끼임 | 장갑·옷소매가 회전체에 감김 | 장갑 미착용, 소매 정리 |
| 물체 비래 | 척 렌치 방치, 공작물 이탈 | 렌치 즉시 회수, 물림 길이 확보 |
| 베임 | 칩을 맨손으로 제거 | 칩 갈고리 사용, 보호장갑은 정지 후에만 |
| 눈 손상 | 칩·절삭유 비산 | 보안경 상시 착용, 방호덮개 폐쇄 |
| 화상 | 가공 직후 공작물 접촉 | 냉각 후 취급 |
| 피부염 | 절삭유 장시간 접촉 | 농도 관리, 접촉 시 세척 |
| 감전 | 젖은 손으로 조작반 접촉 | 물기 제거 후 조작 |

### 4.3 보호구 착용 기준

| 보호구 | 착용 | 비고 |
|---|---|---|
| 안전모 | 필수 | |
| 보안경 | 필수 | 측면 차폐형 |
| 안전화 | 필수 | 발등 보호 |
| 귀마개 | 권장 | 소음 85 dB 초과 시 필수 |
| 장갑 | **금지** | 운전 중 착용 금지, 청소·정비 시에만 |

### 4.4 정비 시 안전

정비, 청소, 공구 교체를 할 때는 **잠금·표지(LOTO)** 를 실시합니다.

1. 기계를 정지시킵니다.
2. 주전원 차단기를 내립니다.
3. 차단기에 개인 자물쇠를 채웁니다.
4. "정비 중 — 조작 금지" 표지를 겁니다.
5. 조작반 기동 버튼을 눌러 전원이 완전히 차단되었는지 확인합니다.
6. 작업이 끝나면 본인이 채운 자물쇠를 본인이 해제합니다.

## 5. 유지보수

`category: equipment`

### 5.1 일일 점검 (작업 시작 전)

| 항목 | 기준 |
|---|---|
| 절삭유 잔량 | 눈금 1/3 이상 |
| 절삭유 농도 | 5~8 % |
| 윤활유 잔량 | 눈금 중간 이상 |
| 척 조 청결 | 칩 없음 |
| 방호덮개·인터록 | 정상 작동 |
| 비상정지 버튼 | 정상 복귀 |
| 이상 소음 | 없음 |

### 5.2 주간 점검 (매주 금요일)

- 척 조 물림면의 마모와 균열을 확인합니다. 물림면이 0.5 mm 이상 마모되면 3개를 한 조로 교체합니다.
- 이송축 가이드에 윤활유를 도포합니다.
- 절삭유 필터를 청소합니다.
- 칩 컨베이어 구동부의 이물을 제거합니다.
- 유압 척 압력이 2.5 MPa인지 압력계로 확인합니다.

### 5.3 월간 점검 (매월 첫째 주)

- 절삭유를 전량 교체합니다. 폐절삭유는 지정 폐기물 용기에 배출합니다.
- 주축 베어링의 온도와 소음을 측정합니다. 정상 온도는 60 ℃ 이하입니다.
- 전기 배선 피복 손상과 접지 상태를 확인합니다.
- 공구대 인덱싱 정밀도를 확인합니다.

### 5.4 소모품 교체 주기

| 부품 | 주기 | 판단 기준 |
|---|---|---|
| 절삭공구 인서트 | 200~300개 가공 | 날 끝 마모, 표면 거칠어짐 |
| 절삭유 | 1개월 | 악취, 농도 이탈, 부유물 |
| 절삭유 필터 | 3개월 | 유량 저하 |
| 척 조 | 12개월 | 마모 0.5 mm 초과 |
| 주축 벨트 | 24개월 | 균열, 장력 저하 |

### 5.5 이상 징후와 조치

| 증상 | 추정 원인 | 조치 |
|---|---|---|
| 가공면이 거칠다 | 공구 마모, 이송 과다 | 인서트 교체, 이송 하향 |
| 치수가 계속 커진다 | 공구 보정값 오류 | 보정값 재입력 |
| 공작물이 흔들린다 | 척 물림 부족, 심압대 미지지 | 물림 압력 확인, 센터 지지 |
| 주축에서 소음이 난다 | 베어링 손상 | 운전 중지, 정비 요청 |
| 절삭유가 나오지 않는다 | 필터 막힘, 펌프 고장 | 필터 청소, 정비 요청 |

## 6. 비상 정지

`category: safety`

### 6.1 비상정지 버튼 위치

- 조작반 우측 상단 (적색 버섯형)
- 기계 좌측 측면
- 칩 컨베이어 배출구 옆

세 곳 중 어느 것을 눌러도 주축과 이송축이 즉시 정지하고 절삭유 펌프가 꺼집니다.

### 6.2 비상정지가 필요한 상황

- 사람의 신체나 옷이 회전체에 닿았거나 감겼을 때
- 공작물이 척에서 빠져나왔을 때
- 불꽃, 연기, 타는 냄새가 날 때
- 이상 소음이나 큰 진동이 발생했을 때
- 방호덮개가 파손되어 칩이 튀어나올 때

### 6.3 비상 시 행동 순서

1. **비상정지 버튼을 누릅니다.**
2. 큰 소리로 **"비상 정지! 멈춰 주세요!"** 라고 외쳐 주변에 알립니다.
3. 주전원 차단기를 내립니다.
4. 부상자가 있으면 무리하게 끌어내지 말고, 회전체에 감긴 경우 척을 역회전시키지 말고 즉시 119에 신고합니다.
5. 관리자에게 보고합니다.
6. 현장을 보존합니다. 원인 조사가 끝나기 전에는 기계를 만지지 않습니다.

### 6.4 비상정지 후 복귀

비상정지 후 재가동은 **관리자 확인 후에만** 가능합니다.

1. 원인을 제거했는지 확인합니다.
2. 비상정지 버튼을 시계방향으로 돌려 복귀시킵니다.
3. 조작반 전원을 다시 켭니다.
4. 원점복귀를 실시합니다.
5. 시운전으로 이상이 없음을 확인한 뒤 작업을 재개합니다.

### 6.5 화재 시

- 절삭유 화재에는 **물을 뿌리지 마십시오.** 기름이 튀어 불이 번집니다.
- ABC 분말소화기 또는 K급 소화기를 사용합니다.
- 소화기는 기계 우측 기둥에 비치되어 있습니다.
- 불길이 1 m를 넘으면 진화를 포기하고 즉시 대피합니다. 대피로는 통로 A를 따라 동쪽 비상구로 향합니다.
- 대피 후 집결지(주차장 B구역)에서 인원을 확인합니다.
