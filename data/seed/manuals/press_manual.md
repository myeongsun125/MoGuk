# PR-120 크랭크 프레스 작업 매뉴얼

> 본 매뉴얼은 교육·시연용으로 작성된 가상 장비 문서입니다. 실제 장비의 사양서·취급설명서를 대체하지 않습니다.

---

## 1. 장비 개요

`category: equipment`

PR-120은 금형 사이에 소재를 넣고 슬라이드를 내려찍어 판재를 절단·성형하는 기계식 크랭크 프레스입니다. 본 사업장에서는 브래킷류 블랭킹과 벤딩 공정에 사용합니다.

프레스는 **끼임 재해가 가장 많이 발생하는 기계**입니다. 이 매뉴얼의 4장과 6장은 반드시 숙지한 뒤 작업하십시오.

### 1.1 주요 제원

| 항목 | 값 |
|---|---|
| 공칭 능력 | 120 톤 |
| 슬라이드 행정(스트로크) | 130 mm |
| 분당 행정수 | 40~70 spm |
| 다이 하이트 | 320 mm |
| 볼스터 크기 | 1,100 × 700 mm |
| 슬라이드 조절량 | 60 mm |
| 급정지 시간 | 320 ms 이하 |
| 기계 총중량 | 9,500 kg |

### 1.2 주요 구성부

- **슬라이드(램)**: 상하로 움직이며 상형을 붙들고 내려찍는 부분입니다.
- **볼스터**: 하형을 올려놓고 고정하는 두꺼운 받침판입니다.
- **금형**: 상형과 하형 한 쌍으로 구성되며, 소재를 원하는 모양으로 절단하거나 구부립니다.
- **크랭크축과 플라이휠**: 모터가 플라이휠을 계속 돌려 회전 에너지를 저장하고, 클러치가 물릴 때 그 힘이 슬라이드로 전달됩니다.
- **클러치와 브레이크**: 클러치는 플라이휠의 힘을 슬라이드에 연결하고, 브레이크는 슬라이드를 정지시킵니다. 두 장치는 항상 한 쌍으로 점검합니다.
- **양수조작식 조작반**: 두 손 버튼을 동시에 눌러야 슬라이드가 내려옵니다.
- **광전자식 방호장치**: 금형 앞을 빛의 막으로 가로막아, 빛이 차단되면 슬라이드를 급정지시킵니다.
- **안전블록**: 금형 교체·점검 시 슬라이드가 떨어지지 않도록 물리적으로 받치는 금속 블록입니다.
- **방호울**: 기계 측면과 후면에서 사람의 접근을 막는 울타리입니다.

### 1.3 운전 모드

| 모드 | 동작 | 용도 |
|---|---|---|
| 인칭 | 버튼을 누르는 동안만 조금씩 이동 | 금형 조정 |
| 1행정 | 1회 내려갔다 상사점에서 정지 | 일반 작업 |
| 연속 | 계속 반복 운전 | 자동 이송 시에만 허용 |

**수동으로 소재를 넣는 작업에서는 연속 모드를 사용하지 않습니다.**

## 2. 작동 원리

`category: process`

### 2.1 힘이 만들어지는 과정

모터가 플라이휠을 일정한 속도로 돌립니다. 플라이휠은 무거운 원판이라 회전하면서 큰 운동 에너지를 저장합니다. 작업자가 기동 신호를 주면 클러치가 물리면서 플라이휠의 회전이 크랭크축으로 전달되고, 크랭크축의 회전이 슬라이드의 상하 직선 운동으로 바뀝니다.

이 구조 때문에 **한 번 클러치가 물리면 슬라이드는 아래로 내려가는 동작을 완료합니다.** 슬라이드가 내려가는 도중에 손을 빼려 해도 시간이 없습니다. 따라서 프레스 안전은 "내려간 뒤 대응"이 아니라 "내려가기 전에 손이 없게 하는" 방식으로 설계됩니다.

### 2.2 하사점과 다이 하이트

슬라이드가 가장 아래로 내려온 위치를 **하사점**이라 합니다. 하사점에서 슬라이드 밑면과 볼스터 윗면 사이의 거리가 **다이 하이트**이며, 금형의 높이가 이 값에 맞아야 합니다. 금형이 다이 하이트보다 높으면 금형이 깨지고 기계가 손상됩니다.

### 2.3 절단과 성형의 원리

- **블랭킹(절단)**: 상형의 펀치가 하형의 다이 구멍으로 파고들면서 판재를 잘라냅니다. 펀치와 다이 사이의 틈(클리어런스)이 판 두께의 5~10 %일 때 절단면이 깨끗합니다. 틈이 너무 좁으면 금형이 손상되고, 너무 넓으면 절단면에 큰 버(burr)가 생깁니다.
- **벤딩(굽힘)**: 판재를 금형 모양대로 눌러 구부립니다. 재료가 원래대로 되돌아가려는 성질(스프링백) 때문에 목표 각도보다 조금 더 구부립니다.

### 2.4 급정지 성능과 안전거리

광전자식 방호장치는 빛이 차단된 순간부터 슬라이드가 완전히 멈출 때까지 시간이 걸립니다. PR-120의 급정지 시간은 320 ms 이하입니다. 이 시간 동안 손이 금형에 닿지 않도록, 방호장치는 금형에서 일정 거리 이상 떨어뜨려 설치합니다. **방호장치를 금형 쪽으로 당겨 설치하면 방호 기능이 사라집니다.**

급정지 시간이 기준을 넘으면 브레이크 라이닝이 마모된 것이므로 즉시 사용을 중지하고 정비를 요청합니다.

## 3. 표준 작업 절차

`category: instruction`

### 3.1 작업 전 점검 (15분)

1. 보호구를 착용합니다. 안전모, 보안경, 안전화, 귀마개를 착용합니다.
2. 금형이 볼스터에 정위치로 고정되어 있고 클램프 볼트가 풀리지 않았는지 확인합니다.
3. 안전블록이 지정 걸이에 걸려 있는지 확인합니다. 기계 안에 남아 있으면 절대 기동하지 않습니다.
4. 광전자식 방호장치의 발광부와 수광부 렌즈를 닦고, 손을 넣어 슬라이드가 정지하는지 확인합니다.
5. 양수조작식 버튼 두 개를 각각 하나씩만 눌러 봅니다. 한 손만으로 슬라이드가 내려오면 즉시 작업을 중지하고 관리자에게 보고합니다.
6. 비상정지 버튼을 눌러 보고 복귀시킵니다.
7. 클러치·브레이크 작동음에 이상이 없는지 확인합니다.
8. 점검표에 서명합니다.

### 3.2 금형 교체

금형 교체는 **2인 1조**로 하며, 자격을 받은 작업자만 수행합니다.

1. 기계를 정지시키고 주전원을 차단한 뒤 잠금·표지(LOTO)를 실시합니다.
2. 슬라이드를 하사점 부근까지 내리고 **안전블록을 삽입합니다.**
3. 상형 클램프를 풀어 슬라이드에서 분리합니다.
4. 하형 클램프를 풀고, 금형을 크레인이나 대차로 옮깁니다. **금형을 손으로 들지 않습니다.** 표준 금형 1조의 무게는 180 kg입니다.
5. 새 금형을 볼스터 중앙에 놓고 위치를 맞춥니다.
6. 하형을 클램프 4개로 고정하고 규정 토크로 조입니다.
7. 슬라이드 높이를 조절해 다이 하이트를 맞추고 상형을 고정합니다.
8. 안전블록을 빼서 지정 걸이에 겁니다.
9. LOTO를 해제하고 인칭 모드로 1행정 돌려 간섭이 없는지 확인합니다.

### 3.3 시운전

1. 인칭 모드로 슬라이드를 천천히 내려 상형과 하형이 어긋나지 않는지 확인합니다.
2. 1행정 모드로 전환하고, 소재 1장을 넣어 시제품을 만듭니다.
3. 치수와 절단면을 검사합니다. 버 높이는 판 두께의 10 % 이하여야 합니다.
4. 검사 합격 후 관리자 승인을 받고 양산을 시작합니다.

### 3.4 양산 작업

1. 운전 모드를 **1행정**에 놓습니다.
2. 소재를 하형에 올립니다. 손으로 직접 올리지 말고 **집게(피더)를 사용합니다.**
3. 두 손을 양수조작식 버튼에서 떼지 않고 슬라이드가 상사점으로 돌아올 때까지 유지합니다.
4. 슬라이드가 완전히 올라간 것을 확인한 뒤 집게로 제품을 꺼냅니다.
5. **금형 안에 손을 넣지 마십시오.** 제품이 금형에 붙었을 때도 손이 아닌 집게나 자석봉을 사용합니다.
6. 스크랩은 스크랩 슈트로 빠지게 하고, 쌓이면 기계를 정지시킨 뒤 치웁니다.
7. 50개마다 1개를 검사합니다.

### 3.5 작업 종료

1. 슬라이드를 상사점에 정지시킵니다.
2. 금형 사이의 이물과 스크랩을 제거합니다.
3. 금형 성형면에 방청유를 얇게 바릅니다.
4. 주전원을 차단합니다.
5. 작업일지에 생산 수량, 금형 상태, 특이사항을 기록합니다.

## 4. 안전 수칙

`category: safety`

### 4.1 반드시 지켜야 할 사항

- **금형 사이에 절대 손을 넣지 마십시오.**
- 소재를 넣고 뺄 때는 반드시 집게, 자석봉, 진공흡착기 중 하나를 사용합니다.
- 양수조작식 버튼을 테이프나 물건으로 고정하지 마십시오. 한 손 조작을 만드는 모든 개조는 금지입니다.
- 광전자식 방호장치를 가리거나 위치를 옮기지 마십시오.
- 방호울과 안전 커버를 떼어 낸 상태로 운전하지 마십시오.
- 수동 이송 작업에서는 연속 모드를 사용하지 마십시오.
- 슬라이드가 완전히 상사점에 멈춘 것을 확인한 뒤에만 금형 근처에 접근합니다.
- 2인 이상이 작업할 때는 기동 전 **"기동합니다"**라고 외치고 상대의 응답을 확인합니다.
- 몸이 좋지 않거나 졸릴 때는 관리자에게 알리고 작업을 교대합니다.

### 4.2 주요 위험 요인

| 위험 | 발생 상황 | 예방 조치 |
|---|---|---|
| 끼임(협착) | 금형 사이에 손을 넣음 | 집게 사용, 방호장치 유지 |
| 슬라이드 낙하 | 금형 교체 중 슬라이드가 내려옴 | 안전블록 삽입, LOTO |
| 물체 비래 | 금형·클램프 파손 조각 비산 | 보안경, 정기 균열 점검 |
| 베임 | 스크랩·소재 모서리 | 보호장갑, 집게 사용 |
| 소음성 난청 | 타격음 반복 노출 | 귀마개 상시 착용 |
| 요통 | 금형·소재 수동 운반 | 크레인·대차 사용 |
| 감전 | 제어반 임의 개방 | 유자격자만 접근 |

### 4.3 방호장치 점검 기준

| 장치 | 확인 방법 | 합격 기준 |
|---|---|---|
| 광전자식 방호장치 | 광축에 시험봉 투입 | 즉시 급정지 |
| 양수조작식 버튼 | 한 손씩 단독 조작 | 슬라이드 미동작 |
| 안전블록 | 걸이 위치 확인 | 기계 안에 없음 |
| 급정지 시간 | 측정기로 계측 | 320 ms 이하 |
| 비상정지 버튼 | 3개소 각각 타격 | 즉시 전원 차단 |

방호장치 점검 항목 중 **하나라도 불합격이면 기계를 사용하지 않습니다.** 붉은색 "사용 금지" 표지를 걸고 관리자에게 보고합니다.

### 4.4 정비 시 안전

1. 기계를 정지시키고 슬라이드를 안전한 위치에 둡니다.
2. 주전원 차단기를 내리고 개인 자물쇠를 채웁니다.
3. "정비 중 — 조작 금지" 표지를 겁니다.
4. 슬라이드 아래에서 작업할 때는 **반드시 안전블록을 삽입합니다.** 유압이나 브레이크만 믿지 않습니다.
5. 정비가 끝나면 안전블록을 회수하고, 기계 안에 공구가 남아 있지 않은지 확인한 뒤 자물쇠를 해제합니다.

## 5. 유지보수

`category: equipment`

### 5.1 일일 점검

| 항목 | 기준 |
|---|---|
| 윤활유 잔량 | 눈금 중간 이상 |
| 클램프 볼트 풀림 | 없음 |
| 광전자식 방호장치 | 정상 급정지 |
| 양수조작식 버튼 | 단독 조작 시 미동작 |
| 비상정지 버튼 3개소 | 정상 |
| 이상 소음·진동 | 없음 |
| 스크랩 슈트 | 막힘 없음 |

### 5.2 주간 점검

- 클러치·브레이크의 에어 압력을 확인합니다. 기준은 0.5 MPa입니다.
- 금형 성형면의 마모, 균열, 눌림을 확인합니다.
- 슬라이드 가이드 틈새를 확인하고 윤활합니다.
- 스크랩 슈트와 배출 컨베이어를 청소합니다.
- 방호울 고정 볼트를 확인합니다.

### 5.3 월간·연간 점검

- **월간**: 급정지 시간을 측정하고 기록합니다. 320 ms를 초과하면 브레이크 라이닝을 교체합니다.
- **월간**: 플라이휠 베어링의 온도와 소음을 확인합니다.
- **월간**: 전기 배선 피복과 접지를 확인합니다.
- **연간**: 크랭크축과 커넥팅 로드의 균열을 비파괴 검사로 확인합니다.
- **연간**: 프레스 안전검사를 받습니다. 검사 합격증은 기계 전면에 부착합니다.

### 5.4 소모품 교체 주기

| 부품 | 주기 | 판단 기준 |
|---|---|---|
| 브레이크 라이닝 | 12개월 | 급정지 시간 초과 |

## 6. 비상 정지

`category: safety`

### 6.1 비상정지 버튼 위치

- 조작반 중앙 (적색 버섯형)
- 기계 좌측 기둥
- 기계 후면 방호울 옆

어느 것을 눌러도 클러치가 즉시 풀리고 브레이크가 걸려 슬라이드가 정지합니다.

### 6.2 비상정지가 필요한 상황

- 사람의 손이나 신체가 금형 쪽으로 들어갔을 때
- 슬라이드가 상사점에서 멈추지 않고 계속 내려올 때
- 금형이나 클램프가 파손되었을 때
- 이상한 타격음, 연기, 타는 냄새가 날 때
- 광전자식 방호장치가 작동하지 않는 것을 발견했을 때

### 6.3 비상 시 행동 순서

1. **비상정지 버튼을 누릅니다.**
2. 큰 소리로 **"비상 정지! 멈춰 주세요!"** 라고 외쳐 주변에 알립니다.
3. 주전원 차단기를 내립니다.
4. 신체가 금형에 끼인 경우 **슬라이드를 임의로 올리지 마십시오.** 잘못 조작하면 2차 손상이 발생합니다. 즉시 119에 신고하고 구조대의 지시를 따릅니다.
5. 슬라이드를 올려야 한다면 관리자와 정비 담당자가 함께, 안전블록을 준비한 상태에서 인칭 모드로 조작합니다.
6. 관리자에게 보고하고 현장을 보존합니다.

### 6.4 비상정지 후 복귀

비상정지 후 재가동은 **관리자 확인 후에만** 가능합니다.

1. 원인을 제거했는지 확인합니다.
2. 금형과 방호장치의 손상 여부를 점검합니다.
3. 비상정지 버튼을 시계방향으로 돌려 복귀시킵니다.
4. 인칭 모드로 1행정 돌려 이상이 없음을 확인합니다.
5. 급정지 시간을 다시 측정합니다.
6. 이상이 없으면 작업을 재개합니다.

### 6.5 화재·정전 시

- **화재**: ABC 분말소화기를 사용합니다. 소화기는 기계 좌측 기둥에 비치되어 있습니다. 전기 화재에는 물을 사용하지 마십시오. 불길이 1 m를 넘으면 진화를 포기하고 대피합니다.
- **대피**: 통로 B를 따라 남쪽 비상구로 이동하고, 집결지(주차장 B구역)에서 인원을 확인합니다.
- **정전**: 정전 시 슬라이드는 그 자리에 정지합니다. 전기가 다시 들어오면 갑자기 움직일 수 있으므로, 정전 중에는 금형 근처에 접근하지 마십시오. 복전 후에는 반드시 주전원을 내렸다가 다시 올리고 원점을 확인한 뒤 작업합니다.
