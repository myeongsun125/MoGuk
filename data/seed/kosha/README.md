# data/seed/kosha — 실자료 수집 자리 [명선]

**이 디렉터리에는 생성물(합성 문서)을 두지 않는다.** 실제 KOSHA(안전보건공단) 배포 자료만 들어온다.

## 수집 예정

- KOSHA **16개국어 안전보건 자료** 중 **기계가공 관련 3~5건** 발췌 예정 — 담당: 명선
- **2025.5 개정 항목**을 반드시 포함
  - 화재·폭발 시 대피
  - 폭염 대응
  - 한파 대응

## 반입 시 규칙

| 항목 | 규칙 |
|---|---|
| 파일명 | `kosha_<주제>_<언어코드>.<확장자>` (예: `kosha_fire_evacuation_vi.pdf`) |
| 원문 보존 | 원본 파일을 수정하지 않고 그대로 둔다 |
| 출처 기록 | 각 파일에 대응하는 항목을 아래 `수집 목록`에 추가 (자료명·URL·발행/개정일) |
| 라이선스 | 공단 자료 이용조건 확인 후 반입. 조건이 불명확한 자료는 반입 보류 |
| 적재 | `documents.origin = 'seed'`, `category`는 자료 성격에 따라 `safety` 우선 |
