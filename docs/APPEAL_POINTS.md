# MoGuk(이음) 발표 어필포인트 — 심사 기준 매핑

작성 2026-08-21 | 심사 기준: 독창성 30 / 구현가능성 30 / 현장효과 30 / 보안성 10
각 항목 = 어필 한 줄 + 시연·증거 + 매핑 기준. 발표 슬라이드와 시연 시나리오는 이 문서에서 파생한다.

## A. 핵심 서사 (오프닝)

**A1. "번역이 아니라 이해의 증명"**
- 한 줄: 전달했는가가 아니라 이해했는가를 데이터로 남긴다.
- 시연: 근로자 퀴즈 통과(90점 기준) → 대시보드에 라벨(빨강 <80 집중교육 / 노랑 80–89 경고 / 초록 ≥90 양호) 실시간 반영.
- 근거: 이해도 = 최신 응시 점수, 통과까지 재시험 — 정의가 명확해 심사 질문("78%가 뭔가요")에 한 문장으로 답 가능.
- 기준: 독창성 + 현장효과

## B. 프라이버시·보안 (보안성 10 + 독창성)

**B1. 상담 데이터 프라이버시 설계** ★메모 어필포인트 ①
- 한 줄: 근로자의 개인 고충 상담은 사업장 밖으로 한 글자도 나가지 않고, 관리자조차 함부로 못 본다.
- 시연: 상담 챗은 로컬 LLM 전용 티어(trace에 tier='local' 표시) → 관리자 화면은 위험 신호 요약만 노출 → "세부사항" 버튼으로 원문 진입 시 access_logs에 열람 기록 생성되는 것을 psql로 보여줌.
- 어필 문장: "업무 효율(요약 우선)과 근로자 프라이버시(열람 감사)를 양립시켰다."
- 기준: 보안성 + 독창성
- 후보(미확정, ① 하위): "미디어 버퍼는 탈취돼도 읽을 수 없다" — edge는 쓰기만, 읽기·목록·삭제는 core만 (M-22/M-25)
  - 한 줄: 버퍼를 올린 쪽(edge)은 다시 읽을 수 없다 — 쓰기와 읽기·목록·삭제 권한을 IAM 정책 수준에서 분리.
  - 시연: PR #9 첨부 캡처(docs/assets/s3-dod-masked.png — 마스킹본: 계정ID·ARN·IP·ETag 가림, AccessDenied 사유·rule-id 원문 유지) — ① edge PUT OK + lifecycle rule-id·SSE AES256 ② edge GET AccessDenied(정책 부재 사유 명시) ③ core LIST+GET ④ core DELETE 후 KeyCount 없음
  - 보강 예정: edge list-objects-v2 거부 캡처 1장(병갑 요청 중)
  - 발표용 마스킹 필수: AWS 계정ID, 버킷명, IAM user ARN, EC2 IP, ETag/체크섬 값 → 병갑이 마스킹본 재제출, 원본 캡처는 리포에 넣지 않음
  - 어필 문장(1안): "관리자도 근로자도 아닌 서버조차 — 버퍼를 올린 쪽은 다시 읽을 수 없습니다"
  - 기준: 보안성
  - 소유: BG / 상태: 후보 / 등록: 2026-08-27 명선

**B2. 온프레미스 격리의 실증**
- 한 줄: 격리는 다이어그램이 아니라 네트워크 설정이다.
- 시연: internal 네트워크 격리(core_net internal:true, `docker network inspect`로 확인) + edge의 내부 DB 자격증명 미보유(env에 없음) + 앱 레벨 단방향(core→edge outbound만, M-22 불변조건 2줄). edge 저장소 암호문(AES-GCM) vs 앱 평문 대비. "차단은 방향이 아니라 능력으로" 한 문장.
- 로드맵 한 줄: 향후 WAF·rate limit(edge 드롭인) → mTLS·DLP·SIEM(운영 단계) — 구현 주장 금지, 설계 시야 어필만.
- 수위 주의: "전송 구간 HTTPS + 저장 시 암호화(외부 존 유출 시에도 평문 노출 없음)"까지만. 브라우저 복호화(E2E)는 로드맵.
- 기준: 보안성 + 구현가능성

**B3. 등급 라우팅 + 외부 장애 폴백 (킬러 데모)**
- 한 줄: 민감은 로컬, 비민감만 외부 — 그리고 외부가 죽어도 서비스는 멈추지 않는다.
- 시연: 발표 중 외부 API를 의도적으로 차단 → 어댑터가 로컬로 자동 전환, 응답 지속. 전환 시간·성공률 실측치(8/30 측정 #5) 제시.
- 기준: 보안성 + 구현가능성 + 현장효과

**B4. "보안 결함 3건을 배포 전에 차단"** (보존 원칙 — 모든 버전에서 유지)
- 갱신(8월 4주): +3건 추가 — A-04 비밀번호 하드코딩 제거, Trivy HIGH 36건 머지 전 차단, prod ports 병합 결함(!reset) 리뷰 차단. 발표 문장: "예선 3건, 본선 준비 중에도 3건 — 검문이 계속 작동한다." 근거 = docs/WORKLOG/.
- 한 줄: CI 3단 검문(형식→보안→동작)이 실제로 작동한 증거.
- 기준: 보안성 — 유일한 실증 구현 증거이므로 발표·문서 어디서도 삭제 금지.

## C. 안전 관리 체계 (현장효과 30)

**C1. 위험 보고 3단계 상태 머신** ★메모 어필포인트 ②
- 한 줄: 위험 보고는 접수로 끝나지 않는다 — submitted→acknowledged→resolved 각 전이가 승인·기록점이다.
- 시연: 베트남어 음성 보고 → 202 즉시 접수 → 백그라운드 STT+요약+심각도 → 대시보드 "미확인 위험보고" 카운트 증가 → 관리자 확인(acked_by/at 기록) → 조치 완료(resolution_note).
- 추가 어필: STT 3회 실패 시에도 오디오 보존 + "직접 청취 필요" 알림 — 안전 크리티컬 정보는 시스템 장애로도 유실되지 않는다.
- 기준: 현장효과 + 구현가능성

**C2. 교육일지 자동 생성**
- 한 줄: 근로감독관이 가장 먼저 찾는 서류를, 버튼 하나로, 이해도 데이터까지 붙여서 출력한다.
- 근거: 교육일지·참석자 명단은 3년 이상 보관 의무 증빙이고 법정 지정 서식은 없음(필수 기재사항만 존재) → 일시·구분·내용·강사(자격 근거)·참석자·이해도 점수를 우리 데이터에서 자동 조립.
- 시연: 안전 코스 완료 → 일지 PDF/HTML 출력.
- 수위 주의: "법정 시간 이수를 대체한다" 주장 금지. "법정 교육의 전달·검증·증빙을 보조" — 기획서의 '증빙 부담 완화'와 동일 선.
- 기준: 현장효과 (사업주 도입 동기의 실체)

**C3. 고위험 선별 게이트 실측치** ★메모 어필포인트 ③
- 한 줄: 안전 관련 응답만 백트랜슬레이션 게이트로 차단하고, 임계값은 감이 아니라 실측으로 정했다.
- 시연: 오류 검출률 XX% (오탐률 YY%, τ=0.ZZ) + 오염 유형(용어 치환/부정 반전/수치 변경) 곡선 슬라이드 1장. "누르지 마세요→누르세요"를 게이트가 잡는 라이브 데모 가능하면 최상.
- 판정 주체 문장: "고위험 여부는 시스템이 자동 판정(질의 분류 OR 청크 메타)하되, 기준의 최종 소유자는 관리자다."
- 기준: 독창성 + 구현가능성 — 기획서 "[측정 후 기입]" 칸을 채웠다는 것 자체가 약속 이행 증거.

## D. 지식 자산·아키텍처 (독창성 + 구현가능성)

**D1. 축적 루프의 세 입구**
- 한 줄: 쓸수록 두꺼워진다 — 용어 후보 추출, 반복 질문의 퀴즈화, 그리고 관리자 답변의 지식베이스 자동 편입.
- 시연: 무근거 질문 → 관리자 큐 → 답변 → documents(origin='admin_answer')로 편입 → 같은 질문 재입력 시 근거 있는 답변.
- 기준: 독창성

**D2. Dagster 자산 그래프 = 살아있는 lineage**
- 한 줄: 문서→청크→용어사전→퀴즈→리포트가 자산 그래프로 UI에 그려진다.
- 시연: Dagster UI 화면 그대로. "오케스트레이터는 기획 단계 Airflow 검토 후 자산 lineage 시각화와 경량 운영 이점으로 Dagster로 최적화" 한 줄 처리.
- 기준: 구현가능성 + 독창성

**D3. 무근거 응답 차단 100%**
- 한 줄: 환각은 근거 강제로 막는다 — 근거 없는 응답 0건을 쿼리 한 줄로 증명.
- 시연: qa_logs에서 sources 빈 응답 카운트 = 0 라이브 쿼리. trace JSONB로 임의 응답의 처리 이력(분류→검색→라우팅→검증) 열람.
- 기준: 구현가능성 + 보안성

**D4. 테넌트 완전 분리**
- 한 줄: 사업장별 데이터 분리는 옵션이 아니라 스키마다.
- 시연: psql \dn — 테넌트별 PostgreSQL 스키마가 물리적으로 분리된 것을 그대로 보여줌.
- 기준: 보안성

## E. 발표 금지 문구 (감점 방지)

1. "법정 안전교육 시간을 우리 서비스로 이수한다" — 금지. 강사 요건 있는 실시가 전제, 우리는 전달·검증·증빙 보조.
2. "종단간(E2E) 암호화" — 금지. 저장 시 암호화 + HTTPS까지만. 브라우저 복호화는 로드맵.
3. Airflow 언급 회피 금지 — 기획서에 인쇄돼 있으므로 먼저 한 줄로 선제 처리(D2 문구).
4. 미측정 수치 단정 금지 — 측정 전 항목은 "측정 방법과 목표"로만 말하고, 8/29–30 실측 후 숫자로 교체.

## F. 시연 시나리오 골격 (리허설용)

1. QR 스캔 → 언어 선택 → 학습카드 → 퀴즈 90점 통과 (A1)
2. 베트남어 질문 → 근거 출처 답변 → trace 열람 (D3)
3. "누르지 마세요" 오역 게이트 차단 (C3)
4. 음성 위험 보고 → 대시보드 → 확인→조치 (C1)
5. 외부 API 차단 → 폴백 지속 (B3)
6. 관리자: 승인큐 → 용어 편입, 무근거 질문 답변 → 편입 (D1)
7. 교육일지 출력 (C2)
8. 마무리: psql \dn + 암호문 + 감사 로그 (B1·B2·D4)
